## Things I've built

### 📄 RAG-Based AI Document Chatbot
Upload a document and ask it questions in plain English. It processes the file, creates embeddings, retrieves the most relevant chunks from a FAISS index, and answers with an LLM that has the right context. LangChain orchestrates it, a FastAPI backend serves it, and a React frontend sits on top.
`Python` `LangChain` `OpenAI` `FAISS` `FastAPI` `React`

### 🤖 [AI Resume Analyzer & Job Matching](https://github.com/Abhi-n-a-v/ai-resume-analyzer)
Paste in a resume and a job description, and it tells you how well they match. It gives you a match score, a skill-gap analysis, and concrete suggestions to improve the resume. It extracts text from PDFs, runs NLP and LLM analysis, stores results in PostgreSQL, and ships in Docker.
`Python` `FastAPI` `NLP` `LLM` `PostgreSQL` `Docker`

### 🗓️ [Interview Scheduler](https://github.com/Abhi-n-a-v/interview-scheduler)
A full-stack platform for scheduling interviews, with conflict detection so nobody gets double-booked and a dashboard with analytics. I designed the relational models, built the REST APIs, and wired the React frontend to them.
`React` `Django REST Framework` `PostgreSQL` `Tailwind CSS` `Docker`

### 💰 [Finance Tracker](https://github.com/Abhi-n-a-v/FinanceTracker)
A full-stack personal finance tracker with user accounts, transaction tracking, and spending analytics.
`Django REST Framework` `React`
